# موظف AI مصري (واتساب + موقع)

MVP شغال بدون مفاتيح: رد ذكي تجريبي + حجوزات + داشبورد + موقع عام.

## تشغيل
```
npm install
copy .env.example .env
npm run dev
```
- الموقع العام للمرضى: http://localhost:3000/site.html (خدمات/دكاترة/حجز أونلاين بالتقويم)
- اللوحة: http://localhost:3000 (دخول: admin أو reception أو doctor)
- اختبارات: `npm test` (99 حالة)

جرب تكتب: "بكام الكشف؟" / "عايز احجز بكرة الساعة 5"

## ربط واتساب حقيقي (اليوم 3-4)
1. اعمل App على developers.facebook.com > WhatsApp > API Setup
2. حط `WHATSAPP_TOKEN` و `WHATSAPP_PHONE_NUMBER_ID` في `.env`
3. شغل سيرفر مكشوف (ngrok): `ngrok http 3000`
4. في Meta حط Callback URL: `https://xxx.ngrok-free.app/webhook` و Verify Token زي اللي في `.env`
5. ابعت رسالة لرقم التيست وهيرد عليك بالمصري.

## ربط OpenAI (اليوم 5)
حط `OPENAI_API_KEY` في `.env` وهيتحول من الرد التجريبي للرد الذكي الكامل (GPT-4o-mini).
التكلفة: ~0.002$ لكل محادثة.

## الحماية من مشاكل الواقع (متنفذة)
- منع الحجز المزدوج: `src/schedule.js` بيحول المعاد لتاريخ حقيقي ويمنع التضارب لنفس الخدمة + بيقترح بدائل.
- الإجازات والمواعيد: `schedule` في `business-config.json` (فتح/قفل/أيام إجازة) وأي حجز براها بيترفض بأدب.
- "الساعة 5" الغامضة: بيسأل الصبح ولا المغرب قبل ما يسجل.
- الرقم الغلط: لازم 010/011/012/015 + 11 رقم، غير كده بيطلب الرقم الصح.
- تحويل لبشري: "عايز أكلم حد/مش فاهم" → تبويب 🙋 في الداشبورد + `GET /api/handoffs`.
- تذكير تلقائي لحجوزات بكرة الساعة 8 بليل (cron) + تجربة فورية: `POST /api/remind-now`.
- تعديل المعاد: "أجل/انقل/غير الحجز" بنفس الرسالة أو على خطوتين، بنفس التحقق (تضارب/إجازة/مواعيد).
- الفويس: `src/voice.js` بيفرغ رسايل الواتساب الصوتية بـ Whisper (محتاج `WHATSAPP_TOKEN` + `OPENAI_API_KEY`)، ولو مش متفعل بيطلب كتابة بأدب.
- داتابيز SQLite (`data.db`): الحجوزات والرسائل والمرضى وحالة المحادثات محفوظة حتى بعد الـ Restart (ترحيل تلقائي من `data.json`).
- تقويم دكاترة: كل دكتور ليه أيام (`days` في الكونفيج) والحجز بيتعين تلقائياً على دكتور فاضي من نفس التخصص.
- تأكيد بعد التذكير: التذكير بيطلب (تأكيد/إلغاء)، واللي ميأكدش بيتكنسل تلقائي قبل معاده بساعتين (`POST /api/autocancel-now` للتجربة).
- حضور/غياب من جدول الحجوزات + تبويب 📊 تقارير (إيراد متوقع/حضور/غياب/نسبة الغياب/تخصصات).
- ذاكرة المريض: الترحيب بالاسم وآخر كشف محجوز.
- حماية سبام: 15 رسالة/دقيقة لكل رقم. قوالب واتساب: `WHATSAPP_REMINDER_TEMPLATE` للتذكير الرسمي (قاعدة الـ 24 ساعة).
- 🔒 قفل اللوحة: حط `DASHBOARD_PASSWORD` في `.env` واعمل restart — أي حد من غيره بيتحول لصفحة دخول.
- 💾 نسخة احتياطية يومية 3 الفجر في فولدر `backups` (آخر 7) + زر نسخ فوري من الإعدادات.
- 🌙 حجوزات الليل (بره 10ص–11م) بتتسجل "محتاجة مراجعة" وبتتأكد من جدول الحجوزات الصبح.
- 📣 متابعة الغايبين أول كل شهر (افتراضي 6 شهور، `RECALL_DAYS`) + زر إرسال فوري من التقارير.

## الإعداد
- عدّل `business-config.json` لكل عميل (أيام/إجازات كل دكتور والأسعار) من تبويب الإعدادات.
